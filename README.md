# World News Video Telegram Bot

Telegram-бот на Python, который собирает мировые новости из RSS-источников,
показывает их через inline-кнопки и отдельно выделяет материалы, похожие на видео.

## Локальный запуск

1. Установить Python 3.11+.
2. Создать виртуальное окружение.
3. Установить зависимости:
   pip install -r requirements.txt
4. Создать `.env` по образцу `.env.example`.
5. Вставить токен Telegram-бота.
6. Запустить:
   python bot.py

## Bothost

Рекомендуемый вариант — загрузить репозиторий GitHub и указать:
- язык: Python
- точка входа: bot.py
- ветка: main
- переменная окружения: BOT_TOKEN

Если Bothost предлагает использовать Dockerfile, включите собственный Dockerfile.

## Важно

Бот использует RSS и ссылки на оригинальные публикации. Он не скачивает
и не перепубликует чужие ролики массово. Если издатель предоставляет
прямой видеофайл через RSS enclosure, бот может попытаться отправить его
в Telegram; иначе пользователь получает кнопку на официальный материал.
